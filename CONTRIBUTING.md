# Участие в проекте

[← README](README.md)

## Вопрос или ошибка

Создайте GitHub Issue. Укажите шаги воспроизведения, ожидаемое и фактическое поведение, версии Node.js, Terraform и YC CLI. Для ошибки облачного сценария уточните этап: инфраструктура, публикация приложений, триггер или запрос Mini App.

Прикладывайте только обезличенные сообщения ошибок. Не публикуйте токены, JSON-ключи, `.env`, `initData`, данные пользователей и Terraform state. Сведения об уязвимости с рабочими учётными данными не размещайте в публичном issue.

## Изменения

1. Создайте ветку и внесите изменение с понятной областью задачи.
2. Обновите документацию, если меняются настройка, API или порядок развёртывания.
3. Добавьте тесты для нового поведения или исправляемой ошибки.
4. Выполните из корня проекта:

   ```bash
   npm ci
   npm run typecheck
   npm test
   npm run build
   ```

5. В pull request опишите проблему, результат, проверки и совместимость с существующими данными.

Для изменений облачной инфраструктуры приложите обезличенный план Terraform и результат проверки на отдельном тестовом стенде, если она выполнялась. Не заявляйте проверку в облаке на основании одной локальной сборки. Для Worker отдельно указывайте локальную проверку и реальное развёртывание.
